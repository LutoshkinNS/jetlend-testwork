## Запуск

### Переменные окружения

Создайте файл `.env` в корне проекта:

Например:
```env
VITE_API_URL=https://jetlend.ru
PLAYWRIGHT_BASE_URL=http://localhost:3001
```

- `VITE_API_URL` — базовый домен API (только в production-сборке)
- `PLAYWRIGHT_BASE_URL` — адрес запущенного приложения

### Установка зависимостей

```bash
npm install
```

### Разработка

```bash
npm run dev
```

Приложение будет доступно на `http://localhost:3001`.

### Production-сборка

```bash
npm run build
npm run preview
```

## Тесты

### Unit и компонентные тесты (Vitest)

```bash
npm run test
```

### E2E тесты (Playwright)

Перед первым запуском установите браузеры:

```bash
npx playwright install
```

Запуск тестов (dev-сервер поднимается автоматически):

```bash
npm run test:e2e
```

С UI-интерфейсом:

```bash
npm run test:e2e:ui
```

Необходимо написать функцию, которая получит данные из трёх источников и предоставит единый массив пользователей с суммарной оценкой по задачам и разбивкой по проектам.

**Источники данных:**

- [projects.json](https://jetlend.ru/media/files/hr/frontend/projects.json)

- [tasks.json](https://jetlend.ru/media/files/hr/frontend/tasks.json)

**Структура данных результата:**

```ts
{
  name: string;
  total_estimate: number;
  projects_estimates: {
    name: string;
    total_estimate: number;
    tasks: Task[];
  }[];
}[]
```

### Задание 7 — Модальное окно подтверждения

Необходимо разработать модальное окно с подтверждением соглашения об использовании функционала платформы.

**Сценарий:**

1. Пользователь нажимает кнопку «Выполнить действие».
2. Открывается модальное окно со следующей структурой:
   - Заголовок: «Согласие с правилами»
   - Крестик закрытия в правом верхнем углу
   - Текст: *«Для данной функции применяются особые условия и правила пользования, их необходимо подтвердить, нажав на кнопку Подтвердить»*
   - Кнопки внизу: «Отмена» и «Подтвердить»

**Поведение кнопки «Подтвердить»:**

- Заблокирована первые 5 секунд после открытия окна
- При повторном открытии счётчик сбрасывается до 5 сек
- Текст кнопки отображает оставшееся время: `Подтвердить (5)` → `Подтвердить (1)` → `Подтвердить`

**После подтверждения:**

- Окно закрывается
- На экране показывается сообщение «Действие выполнено» (например, через `alert`)
- Повторное нажатие «Выполнить действие» больше не открывает диалог — действие выполняется сразу

> Примечание: задание рекомендуется выполнить в prod-like стиле как часть продуктовой разработки. Оценивается не только корректность результата, но и качество кода: читаемость, соответствие стандартам, документация, тесты.
